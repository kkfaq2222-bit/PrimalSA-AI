# 背包（bagpanel）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「背包」1120,760。**ESC 一次就關掉整個背包**（不管停在哪個分頁）。
- 左欄：角色頭像 DKB0 83,195 / DKB02 83,322 / DKB03 83,450 / DKB04 83,580 / DKB05 約 83,700。點了黃框移過去，**穿戴 / 卸下就作用在那個角色**（2026-10-09 實測），不用到切換面板改「當前」角色；「當前登錄」紅標不會動。多角色處理背包一律用這個。
- 中間：裝備格＋HP/MP/攻防敏/屬性。
- 右側：道具格 5×4（第一格 752,236）。點道具 → 道具浮窗（名稱、類別、詳細介紹、**使用 / 丟棄**）；ESC 關閉。
- 下方：顯示道具名、刪除管理（**紅區**）、整理背包。
- 右側分頁：背包 1318,265 / 倉庫 **1318,467**（個人 / 公共、擴容、倉庫頁；操作見下方「倉庫」）/ 圖鑑 **1318,668**（材料圖鑑合成：合成斧頭類、棍棒類…；配方見 `knowledge/crafting/`）。
- 「丟棄」是紅區（不可逆）。

## 道具浮窗按鈕（2026-10-09 實測）
- 道具格：第 1 列 y=245、第 2 列 y=352、第 3 列 y=460；x = 752 / 860 / 966 / 1072 / 1180。
- 消耗品 / 禮盒：「使用」628,648、「丟棄」838,648（紅區）。可疊加的材料類（例：2倍智慧果）是「使用」618,648 /「更多」825,648。不可丟的道具只有一顆「使用」在 732,648。
- 裝備：「穿戴」618,662、「丟棄」826,662（紅區）。穿上後格子變空，其他道具不移位。
- 用不了時畫面上方會跳提示，例「角色1轉1級才能使用」。
- 新角色開禮盒、穿新手裝的完整流程見 `notes/new-account.md`。

## 倉庫（2026-10-09 實測）
入口：背包 → 右側「倉庫」1318,467。左半是倉庫格（5×4，倉庫 1/1 頁），右半是背包格（座標同背包）。
- 分頁：**個人 307,200**（每個角色各自一個）/ **公共 547,200**（全帳號共用，同種道具會疊加，例 5 個角色的誘餌疊成 50）。
- **存入：在右半背包道具上雙擊**（`gui.sh dclick X Y`）。單擊會開浮窗，按「存入」732,648 也可以。
- 取出：單擊左半倉庫格 → 浮窗「取出」732,648。**不要盲目連點「點格子 → 取出」重試**：格子已空時不會開浮窗，732,648 會點到背包下方「刪除管理」的左緣，進入刪除模式（2026-10-09 實際發生，按「取消刪除」968,688 退出）。每次重試前先截圖確認浮窗有開。**沒有數量選擇，整疊一次全取出**（2026-10-09 實測：2倍智慧果 5 顆全拿出來）。只要一部分 → 取出後用完再雙擊存回。
- **戰鬥中無法操作**：開著原地遇敵 + 快速戰鬥時，存入 / 取出常被擋（提示「戰鬥中無法操作」）；連點幾次 `dclick`（間隔 1.5 秒）抓兩場戰鬥之間的空檔就會成功。背包「使用」道具不受影響。
- 「擴容」274,683 可能花錢 → 紅區，要先問。
- 有些道具禁止放公共（Item 表 `banPubDepot=1`）：雙擊會跳「【xxx】禁止存入公共倉庫」，不會移動；改切「個人」再雙擊。例：1轉新手禮盒。
- 倉庫畫面左欄頭像也能直接切角色（同背包）。
- 多角色全存（公共 4 樣 + 個人 1 樣）：
```
bash tools/gui/gui.sh seq "click 83 <頭像Y>; wait 700; click 547 200; wait 600; \
  dclick 752 352; wait 900; dclick 860 352; wait 900; dclick 966 352; wait 900; dclick 1072 352; wait 900; \
  click 307 200; wait 600; dclick 1180 352; wait 900; shot"
```

## NPC 商店（便利店，2026-10-09 實測）
- NPC 對話選「道具商店」後開「便利店」面板：左邊商品格（2 欄，例：第 2 欄第 3 列 670,440），右邊顯示能力 / 技能、數量 −/+、總價。
- 「購買」995,592 → 提示「需要花費 石幣 N」→ **確定 615,557** / 取消 813,557。扣石幣後跳「獲取道具」。ESC 關閉。
- 花石幣屬遊玩決策，只在使用者交代時買。
- 裝備等級需求不一定擋：溫蒂妮Lv5的金幣（Lv60）25 級的 DKB0 也穿得上。

## 便利商店 1009 買材料（2026-10-09 實測）
- 薩姆吉爾村 (106,91) 出口進 1009 落 10,25。素材屋是櫃檯後面的 NPC，站櫃檯外側：`walk.py 1009 24 17` 點 (817,305) = 素材屋(石、木) 2810；`walk.py 1009 24 24` 點 (815,300) = 素材屋(牙、皮) 2811。對話框「道具商店」948,462。
- 商品清單很長（2 欄），用 `drag 540 600 540 250` 往下捲；**拖完要等 1.5 秒讓清單停穩再點**，否則會點到捲動中的別格。古代木在石、木店捲一次後（670,195）；強的繩在牙、皮店捲兩次再回拉 `drag 540 300 540 450` 後（670,480）。
- 數量「＋」1112,466 一次加 1（點 9 次 = 10）；購買 995,592 → 確定 615,557（5000 石幣 / 10 個）。

## 圖鑑合成（2026-10-09 實測，合成弓箭 8 / 9）
- 背包 → 圖鑑 1318,668 → 左欄分類（點一下展開、再點收合；弓箭類 300,490）→ 展開後品項 3 欄格；`drag 300 650 300 300` 捲動（不要一次拉太多）。弓箭 8 在 (307,375)、弓箭 9 在 (402,315)（捲到弓箭 4～9 可見時）。
- 選品項後中間顯示「擁有：N」、屬性；**「兌換」627,681** → 彈出「快速合成」視窗（所需物品 + 石幣 1000）→ **「合成」482,553**（扣材料 + 1000 石幣，獲得道具）。這是正常合成，不是花 100 萬的一鍵完成。
- 連續合成：`click 627 681; wait 500; click 482 553; wait 900` 重複。實測合成弓箭 8 ×10、弓箭 9 ×5 共 15 次全部成功（沒遇到失敗），每次只扣 1000 石幣 + 材料。
- 裝備類成品不疊加，每把占一格。

## 公共倉庫轉移裝備給其他角色（2026-10-09 實測）
- 弓箭可存公共倉庫（無 banPubDepot）：DKB0 倉庫 → 公共 → `dclick` 背包格存入；左欄點 DKB02 頭像（倉庫畫面也有效）→ 公共分頁 → 單擊倉庫格 → 浮窗「取出」722,662（弓箭浮窗的取出鈕在 722,662，消耗品是 732,648）→ 背包分頁 → 點道具 → 穿戴 618,662。
- 切到別的角色後「倉庫」分頁會回到個人，要再點公共 547,200。
