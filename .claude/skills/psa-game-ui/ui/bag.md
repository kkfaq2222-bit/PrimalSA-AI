# 背包（bagpanel）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「背包」1120,760。**ESC 一次就關掉整個背包**（不管停在哪個分頁）。
- 左欄：角色頭像 DKB0 83,195 / DKB02 83,322 / DKB03 83,450 / DKB04 83,580 / DKB05 約 83,700。點了黃框移過去，**穿戴 / 卸下就作用在那個角色**（2026-10-09 實測），不用到切換面板改「當前」角色；「當前登錄」紅標不會動。多角色處理背包一律用這個。
- 中間：裝備格＋HP/MP/攻防敏/屬性。
- 右側：道具格 5×4（第一格 752,236）。點道具 → 道具浮窗（名稱、類別、詳細介紹、**使用 / 丟棄**）；ESC 關閉。
- 下方：顯示道具名、刪除管理（**紅區**）、整理背包。
- 右側分頁：背包 1318,265 / 倉庫 **1318,467**（個人 / 公共、擴容、倉庫頁；操作見下方「倉庫」）/ 圖鑑 **1318,668**（材料圖鑑合成：合成斧頭類、棍棒類…；配方見 `knowledge/crafting/`）。
- 「丟棄」是紅區（不可逆）。

## 道具浮窗按鈕（2026-10-09 實測）
- 道具格：第 1 列 y=245、第 2 列 y=352、第 3 列 y=460；x = 752 / 860 / 966 / 1072 / 1180。
- 消耗品 / 禮盒：「使用」628,648、「丟棄」838,648（紅區）。不可丟的道具只有一顆「使用」在 732,648。
- 裝備：「穿戴」618,662、「丟棄」826,662（紅區）。穿上後格子變空，其他道具不移位。
- 用不了時畫面上方會跳提示，例「角色1轉1級才能使用」。
- 新角色開禮盒、穿新手裝的完整流程見 `notes/new-account.md`。

## 倉庫（2026-10-09 實測）
入口：背包 → 右側「倉庫」1318,467。左半是倉庫格（5×4，倉庫 1/1 頁），右半是背包格（座標同背包）。
- 分頁：**個人 307,200**（每個角色各自一個）/ **公共 547,200**（全帳號共用，同種道具會疊加，例 5 個角色的誘餌疊成 50）。
- **存入：在右半背包道具上雙擊**（`gui.sh dclick X Y`）。單擊會開浮窗，按「存入」732,648 也可以。
- 取出：推測是雙擊左半倉庫格（未實測）。
- 「擴容」274,683 可能花錢 → 紅區，要先問。
- 有些道具禁止放公共（Item 表 `banPubDepot=1`）：雙擊會跳「【xxx】禁止存入公共倉庫」，不會移動；改切「個人」再雙擊。例：1轉新手禮盒。
- 倉庫畫面左欄頭像也能直接切角色（同背包）。
- 多角色全存（公共 4 樣 + 個人 1 樣）：
```
bash tools/gui/gui.sh seq "click 83 <頭像Y>; wait 700; click 547 200; wait 600; \
  dclick 752 352; wait 900; dclick 860 352; wait 900; dclick 966 352; wait 900; dclick 1072 352; wait 900; \
  click 307 200; wait 600; dclick 1180 352; wait 900; shot"
```
