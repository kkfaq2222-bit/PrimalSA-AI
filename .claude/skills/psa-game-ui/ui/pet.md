# 寵物面板（寵物管理）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

## 入口
主畫面左上寵物頭像 318,80（或「寵物管理」440,145）。ESC 關閉。右側分頁：寵物 / 倉庫 / 圖鑑。

## 畫面內容
- **左欄角色頭像**（同背包）：DKB0 83,195 / DKB02 83,322 / DKB03 83,450 / DKB04 83,580 / DKB05 83,700（被切一半但點得到）。
  點了黃框移過去，之後的設定都作用在那個角色（「當前登錄」紅標不動）。
- 寵物欄 5 格：250,200 / 250,322 / 250,445 / 250,567 / 250,690。左上角紅標是狀態：**戰鬥 / 騎乘 / 等待**。
- 中間：寵物名（鉛筆鈕改名）、模型、轉數；下方三顆狀態鈕 **出戰 390,702 / 騎乘 532,702 / 休息 672,702**（亮的就是目前狀態）。
- 右側：HP、EXP、攻防敏、評分、忠誠（＋－）、屬性、回爐次、總成長；分頁「寵物技能」（7 格）/「成長詳情」；「整理技能」。
- **紅區**：垃圾桶 708,565（丟棄寵物）、回爐 372,610、忠誠＋－（未知消耗，要先問）、鎖頭 708,630（作用未實測）。

## 操作：設定出戰 / 騎乘（2026-10-09 實測）
1. 點左欄頭像選角色 → 點寵物格 → 點「出戰」或「騎乘」。立即生效，無確認框；寵物格紅標會變「戰鬥」/「騎乘」。
2. 部分寵物要先有**騎權**（學騎乘）才能騎：`knowledge/pets/ride.md` 的「需學習」=1 就要先到 NPC 學（NpcScript studyRideLevel）。
   例：瑪斯貝卡（需學習 0，可直接騎）、迪基格斯（需學習 1）。
3. 多角色一次跑完（每個角色的寵物排列要一樣，先截圖確認）：
```
bash tools/gui/gui.sh seq "click 83 <頭像Y>; wait 700; click 250 200; wait 400; click 390 702; wait 700; \
  click 250 322; wait 500; click 532 702; wait 900; shot"
```

- 想讓出戰 / 騎乘狀態固定不被改掉：外掛「一般設置」的鎖定騎寵 / 鎖定戰寵，見 [ass.md](ass.md)。
