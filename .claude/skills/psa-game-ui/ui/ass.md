> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「外掛」1300,760。ESC 關閉。
遊戲官方功能，不算違規外掛；**開來看可以，任何勾選、下拉、數值、SET 都要先問使用者**（使用者交代時照做，例：鎖定騎寵 / 戰寵，見下方）。主畫面「遇敵」1365,660 同理。
- 左上：選角色（DKB0…，黑點 = 選取中）。
- 左欄：戰鬥設定（原地遇敵 146,343、自動逃跑 315,343、**快速戰鬥 484,343**、**自動戰鬥 146,400**、夥伴助戰 315,400；每個角色各自設定）、隱藏設定（隱藏名字、隱藏玩家、全部遮罩）、音量。

- 分頁：戰鬥設置 **696,206** / 一般設置 **850,212** / 捉寵設置 **984,212**。

- 數值欄輸入方式**未實測**：推測是點欄位 → `key` 打數字 → 按旁邊的 SET，第一次做時要截圖確認。

## 鎖定騎寵 / 鎖定戰寵（2026-10-09 實測，使用者授權）
位置：外掛 1300,760 → 一般設置 850,212 →「平時設定」最上面兩列。
- 角色選擇（左上圓鈕）：DKB0 137,151 / DKB02 298,151 / DKB03 461,151 / DKB04 137,204 / DKB05 298,204。下方「當前選擇玩家」會跟著變。
- 鎖定騎寵：勾選框 **656,313**、下拉鈕 **1285,312**。
- 鎖定戰寵：勾選框 **656,377**、下拉鈕 **1285,377**。
- 下拉選單展開在欄位正下方，每列約 42px：第 1 隻 1050,355、第 2 隻 1050,397（順序 = 寵物面板的寵物欄順序；本帳號是 迪基格斯 / 瑪斯貝卡）。
- 勾選框點一下切換（勾 ↔ 不勾），**無確認、無 SET 鈕，立即生效**；關掉面板再開仍保留（DKB0 重開確認過）。
- 未勾選時欄位預設顯示第 1 隻寵物，所以騎寵欄要先改選再勾。
- 本帳號設定：5 個角色都是 騎寵＝瑪斯貝卡、戰寵＝迪基格斯，兩項都勾選（和寵物面板的騎乘 / 出戰一致）。
- 作用（推測）：寵物狀態被改掉時（例如戰鬥後）自動維持指定的騎寵 / 戰寵。

- 2026-10-09 設定後聊天日誌出現過一次「你沒有騎乘【迪基格斯】的許可權!」，來源未確認（推測：某個時間點騎寵欄是迪基格斯且被勾選）。之後在寵物面板查 5 個角色，仍都是 迪基格斯 戰鬥 / 瑪斯貝卡 騎乘，沒有受影響。**騎寵下拉不要選需要騎權的寵物**（`knowledge/pets/ride.md` 需學習=1）。
