## ass.py：讀 / 設左欄戰鬥設定（2026-10-10，`tools/gui/ass.py`）
```bash
uv run --no-project python tools/gui/ass.py get DKB0 [項目...]
uv run --no-project python tools/gui/ass.py set DKB0 自動逃跑 on 自動戰鬥 on 快速戰鬥 off
```
- 項目：原地遇敵 / 自動逃跑 / 快速戰鬥 / 自動戰鬥 / 夥伴助戰（英文別名 encounter flee fast auto partner）；角色 DKB0 / DKB02~05。
- 流程：開面板 → **驗證面板真的開了**（X 1318,90 ≈ 195,127,8 + 五顆角色圓鈕 0,0,0 / 197,227,255）→ 選角色並驗證 → 讀五項 → set 只點與目標不同者、讀回確認（不補點）→ 點 X 關並驗證。每次點面板內座標前都先驗證面板還在（面板沒開時這些座標會穿透到地面讓角色走掉）。
- 主畫面看不到外掛鈕紅字（對話 / 載入）→ 不點，每 1.5 秒重試，最多 40 秒（`OPEN_TIMEOUT`），失敗退出碼 2。
- 退出碼：0 / 1 參數 / 2 面板打不開 / 3 選不到角色 / 4 設定確認失敗 / 5 版面不符 / 6 面板中途消失。耗時 get ≈ 5 秒、set 一項 ≈ 6 秒；戰鬥中會等到戰鬥空檔才打得開（實測有一次 12 秒）。
- **實測：面板開著時戰鬥開始會把面板蓋掉 / 關掉**（set 原地遇敵 off 時遇敵剛好開打 → 退出碼 6「點後面板消失」，重跑即可；設定沒生效就再跑一次）。
- 勾選框像素（2026-10-10 實測，框心）：**未勾 = 255,255,255；已勾 = 其他**：原地遇敵 146,343 已勾 151 / 自動逃跑 315,343 已勾 **90** / 快速戰鬥 484,343 已勾 223 / 自動戰鬥 146,400 已勾 30 / 夥伴助戰 315,400 未勾 255（已勾值未量）。程式一律「不是純白就是已勾」。
