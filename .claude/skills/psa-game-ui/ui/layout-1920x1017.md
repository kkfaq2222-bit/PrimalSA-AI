# 1920×1017 版面（1920×1080 螢幕最大化）

> 座標 = `gui.sh shot` 截圖座標（客戶區 1920×1017 → 截圖 **960×508**，一樣是 `-Scale 2`）。索引見 [README.md](README.md)。
> 其他 `ui/*.md` 的座標都是 2880×1659（截圖 1440×830）版面，**不能直接拿來用**；這份是另外加的一套，原本的不動。

## 怎麼判斷用哪一套
- `bash tools/gui/gui.sh info` → `client=1920x1017 ... shot=960x508` 就用這份。
- `uv run --no-project python tools/gui/layout.py` 印出目前版面；`walk.py`、`stat.ps1` 會自己判斷，不用設定。
- 遊戲沒開時想用 1920×1017 試算：`PSA_LAYOUT=1920x1017 uv run --no-project python tools/gui/walk.py --plan ...`

## 換算規則（只用來估計，能量就直接量）
**地圖畫面（走路的每格位移）依寬度縮放 ×0.667**（1920 ÷ 2880，實測）；**UI 依高度縮放 ×0.613**（1017 ÷ 1659），並貼著畫面邊緣對齊：
- 靠左上的元件：`新 ≈ 舊 × 0.613`
- 靠右的元件：`新x ≈ 960 − (1440 − 舊x) × 0.613`；靠下的元件：`新y ≈ 508 − (830 − 舊y) × 0.613`
- 置中的面板（傳送面板、對話框、背包…）：`新 ≈ 中心 + (舊 − 舊中心) × 0.613`，中心是 (480,254) / 舊 (720,415)
- 實測誤差約 2～5 px（例：傳送鈕換算 899,40，實際 905,38）。按鈕夠大時通常點得到，小按鈕先截圖確認。

## 一行檢查指令（2026-10-11 實測：11111 / 22222 都通過；Windows 原生要 `PSA_GUI_SERVER=1`）
使用者的視窗一律是 1920×1017（2880 是前人的版面，只當參考）。
```
PSA_EXE_MATCH=kkfaq11111 PSA_GUI_SERVER=1 uv run --no-project python tools/gui/team.py check            # 隊伍：1 隊長 + 4 隊員（唯讀，約 10 秒）
PSA_EXE_MATCH=kkfaq11111 PSA_GUI_SERVER=1 uv run --no-project python tools/gui/ass.py check-all         # 5 人 快速 + 自動戰鬥（唯讀，約 10 秒）
PSA_EXE_MATCH=kkfaq11111 PSA_GUI_SERVER=1 uv run --no-project python tools/gui/ass.py fix-all           # 沒勾的才點一次並讀回（未實跑，沒有可測對象）
```
- `team.py status|check` 在 1920 版面走 `team1920.py`：純像素、名字只回卡片順序（DKBO、DKBO2…），沒有 OCR / 名字樣板；`disband` 仍只支援 2880。
- 切換面板（1920）：開啟鈕 533,465（換圖後右鍵 2 次 + 左鍵 1 次）、✕ 698,125（紅 183,65,41）；卡片左欄 x0=308 / 右欄 502，列 y0=164 / 218 / 272；存在 = (x0+157,y0+6) 米色 (251,229,199)，空位棕 (169,127,84)。
- 外掛面板（1920）：開啟鈕 872,462、✕ 855,50（橘 195,127,8）；角色圓鈕 113,89 / 214,89 / 317,89 / 113,122 / 214,122；勾選框 原地遇敵 120,208、快速戰鬥 333,208、自動戰鬥 120,243、夥伴助戰 226,243（純白 255,255,255 = 沒勾）。
