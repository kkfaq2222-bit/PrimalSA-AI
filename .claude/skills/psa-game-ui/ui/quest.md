## 任務詳情
入口：詳情 368,328。ESC 關閉。
- 左：主線 / 支線分頁；任務清單與狀態（進行中 / 待接取）。
- 中：任務描述、任務獎勵；右：任務介紹。
- 主線 215,215 / 支線 330,215 分頁；清單從標題處上下拖曳捲動（`drag 272 650 272 280`）。
- 待接取的任務中間有「傳送」鈕 624,670（未點；可能花石幣或直接傳送）。
- 接取 / 回報 NPC 與座標查 `knowledge/quests/tasks.md`；條件（等級、前置任務）查 `knowledge/quests/guides.md`，和遊戲內「任務描述」相同。

## NPC 對話框（2026-10-09 實測）
- 右側棕色框：NPC 名、台詞，下方兩顆鈕 **左 948,461（推進：覲見村長 / 步入世界 / 完成）**、**右 1220,461（再見）**。
- 隊伍中由隊長對話，任務獎勵**全隊每人都拿**（例：初入石器 5 人各得 5000 石幣）。

## 新角色任務進度（2026-10-09）
1. 初入石器：點任務條目 → 老村長「覲見村長」→「完成」。獎勵：石幣 5000×每人、經驗，0 轉 1→2 級。
2. 覲見村長：點任務條目 → 老村長「步入世界」→「完成」。獎勵：經驗、石幣，→3 級。
3. 之後全部卡等級：成人儀式要 0 轉 30 級；其餘支線都要先完成成人儀式；四大洞窟、英雄島前傳 80 級；漆黑洞窟（轉生）131 級以上。
