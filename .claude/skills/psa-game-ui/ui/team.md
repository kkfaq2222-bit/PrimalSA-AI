# 切換角色 / 組隊

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

## 切換角色
入口：主畫面「切換」763,760。ESC 關閉。
- 每個角色一列：狀態（**當前** / 線上）、隊伍狀態（單人 / 隊長 / 隊員）、正常、Lv。**看組隊結果最可靠的地方**。
- 標「當前」的就是目前操作的角色。
- **角色真名是字母 O：DKBO、DKBO2～5；本檔與其他舊文件的 DKB0～DKB05（數字 0）同義**（程式比對 O / 0 視為相同，CLI 的 `--leader` / `--set-char` / ass.py 角色參數兩種寫法都收，輸出用真名）。
- **切換角色優先用 `char.py`**（P3，2026-10-11 實測）：`uv run --no-project python tools/gui/char.py current|switch DKBO2|ensure DKBO`。
  點卡片前先用 namematch 確認名字 + 狀態線上（命中不了 → 61，不猜），點完等「加載中」→ HUD 回來 → 重開面板用「當前藍框 + 名字」驗證，成功才寫 current-char.json；最後一行印 JSON（`changed`、`current`…）。
  退出碼 60 面板打不開 / 61 目標卡找不到或名字沒確認 / 62 點了但當前沒變（不重點）/ 63 當前框 ≠ 1 / 64 名字矛盾 / 65 點了但 HUD 6 s 沒回來，加共用 1 / 2 / 8 / 9 / 10。
  **不會自動切回 DKBO**，呼叫端用完要 `ensure DKBO`。實測耗時：current ≈ 4.5 s、ensure（已是）≈ 4.3 s、switch ≈ 7.5～8 s（含 preflight + 兩次開面板讀名字；點擊到 HUD 回來 0.8～1.3 s）。
  以下手動流程只當退路。
- **點角色卡片就切成「當前」角色**（無確認框，約 1.5 秒；2026-10-09 實測；點後面板自己關、會出現全螢幕「加載中」）。卡片：DKB0 620,300 / DKB02 930,300 / DKB03 620,385 / DKB04 930,385 / DKB05 620,470。組隊中切換不影響隊長 / 隊員身分。
- 按鈕：快速組隊 **520,578** / 全部登錄 716,578 / 刷新角色 910,578。

## 快速組隊
5 個角色組成一隊。**要執行時用 `/psa-quick-team` skill**（含檢查與失敗處理）；以下是介面參考。
1. 切換 763,760 → 快速組隊 **520,578** → 跳出「提示」視窗。
2. 上排「隊長」點**第一個** 549,320（DKB0）→ 卡片出現紅色「隊長」標籤，下排出現其餘 4 人。
3. 下排 4 人**每個都要點一下**：549,520 / 682,520 / 815,520 / 948,520 → 每張出現藍色「隊員」標籤。沒點的人不會入隊。
4. 組隊 **720,665** → 左側組隊分頁出現隊員列表（隊長有紅色「隊」字），聊天日誌「DKB0x 加入了隊伍」。
- 組隊完成後，**隊長會變成「當前」操作的角色**（畫面切到隊長視角，會出現「加載中」）。之後的移動、對話都由隊長操作。
- 只選隊長、不點隊員就按組隊：沒有任何提示，所有人還是「單人」。
- 隊長列可以左右拖曳（`drag`）看被切掉的角色。
- 失敗訊息 33231：「當前地圖不支持一鍵組隊或狀態、條件不滿足」。
- 遊戲說明（800127）：線上且正常狀態的隊員可以直接飛到隊長旁。

## 組隊面板
入口：主畫面「組隊」850,760。ESC 關閉。
- 沒隊伍：5 個隊員格（+）、藍色「創建隊伍」720,670、組隊開關（綠色 = 開）；右側分頁 組隊 / 搜索。
- 有隊伍：5 格列出成員（人物、名字、等級、隊長 / 隊員），按鈕變成紅色「**解散隊伍**」720,670。

### 判斷隊伍幾個人（2026-10-10 實測）
- **組隊面板 850,760（最準，一次 pixel 讀完）**：5 個格子中心 x = 321 / 520 / 719 / 918 / 1117。讀每格左側 (中心 x −27, 320)：**空格是「+」圓鈕的深棕 ≈ (120,88,63)**，有人 = 角色圖背景米色 ≈ (241,215,175)（R > 230）。例：`gui.sh seq "click 850 760; wait 700; pixel 294,320/493,320/692,320/891,320/1090,320; key {ESC}"`，5 個都是米色 = 5 人；少一個就是有人脫隊。另一個備用點 (中心 x, 290)：空格 ≈ (117,86,66)，有人 = 橘色頭髮 ≈ (200,85,23)。
- 格子下方標籤：隊長格「隊長」、隊員格「隊員」；有隊伍時按鈕是紅色「解散隊伍」，沒有隊伍是藍色「創建隊伍」。實測 4 人隊（DKB02 隊長 + DKB03/04/05）：前 4 格有名字 / 等級 / 戰寵頭像，第 5 格仍是「+」。
- **切換角色面板 763,760 交叉確認**：每人一個標籤「隊長 / 隊員 / 單人」。5 人隊 = 1 個隊長 + 4 個隊員；有「單人」的角色就是脫隊（例：DKB0 單人、DKB02 隊長、其他隊員 = DKB0 脫隊，隊長換成 DKB02）。
- **隊伍標籤像素（2026-10-10 實機，`quest.py read_team_labels()` 用）**：每張卡片左側「當前 / 線上」旁有一個深棕小框，框內是「隊長 / 隊員 / 單人」。DKB0 的框左上 ≈ (452,275)、DKB03 (452,360)、DKB05 (452,445)；右欄 DKB02 (762,275)、DKB04 (762,360)（= 左欄 +310）。框內取樣 x = 框左 +6~+34、y = 框上 +8~+22 各隔 2（15×8=120 點）：**「隊長」紅字 ≈ (217,33,33)（實測 30 點）、「隊員」黃字 r>170 g>140 b<110（實測 42~44 點）**，門檻 ≥ 8 點；兩者都不是 → `other`（單人 / 離線 / 卡片不存在；**「單人」的字色沒量過**，所以判斷是「不是隊長也不是隊員 = 不在隊」）。5 人隊 = 1 leader + 4 member 且沒有 other。`quest.py check_team(size)`：開切換 763,760（驗 SIG_PANEL）→ 一次 pixel 讀 5 張 → 點 ✕ 1064,208 關（仍開著再 ESC），約 5~6 秒。實測目前 5 人隊（DKB0 隊長）讀到 leader + 4 member。
- **這個面板只顯示「當前角色」所在隊伍**：當前角色脫隊時看到的是空的組隊面板（5 個 +、藍色創建隊伍），要點切換面板的卡片（DKB02 930,300 等）換成隊長視角才看得到隊伍；左側「組隊」分頁同理（實測看到「DKB0離開了隊伍」系統訊息）。看完用卡片（DKB0 620,300）切回，左側分頁用「任務」148,236 切回。

## 解散隊伍
**要執行時用 `/psa-disband-team` skill**；以下是介面參考。
- **最快**：主畫面左側「組隊」分頁 260,236 → 點隊長那列 210,320 → 彈出選單「解散隊伍」**200,372** /「離開隊伍」200,443。
- 或：組隊面板 850,760 → 解散隊伍 720,670。
- 兩種都**沒有確認框，立即解散**。
- **驗證**：左側組隊分頁變回只有「創建隊伍」就是成功（中央閃「隊伍已經解散」、日誌也有）。
- 實測是以隊長（當前角色）解散；隊員身分時的按鈕未實測。
- **左側分頁像素（2026-10-10 實機）**：「任務」148,236 / 「組隊」260,236 兩個分頁鈕；選中 = 亮米色 R≈205~221、沒選中 = 深棕 R≈80~90。只能取文字上方 y=222、下方 y=250（y=226~246 踩到字會亂跳）：組隊選中 → (130,222)(130,250) ≈ 85~87 暗、(270,222)(270,250) ≈ 205~215 亮；任務選中相反。組隊分頁隊長列左上有紅色「隊」字標，(100,306)(128,306)(100,312)(130,312) ≈ (217,33,33)（任務分頁同位置米色 ≈ (245,223,187)）。`quest.py --disband-after` 用這些點驗證（`tab_state()` / `has_leader_badge()`）。「只剩創建隊伍」與隊員身分的像素沒量到。
- 左側主畫面「組隊」分頁 260,236：沒隊伍時只有「創建隊伍」，有隊伍時列出成員與等級；點成員列會彈出選單（隊長列：解散隊伍 / 離開隊伍）。**這是判斷有沒有隊伍最快的地方**。

## 名字樣板比對 namematch.py（2026-10-11）
- 原理：卡片名字框以咖啡色字（≈125,64,28）二值化 → 與 `tools/.cache/name-tpl/2880x1659.json` 整名樣板做 IoU（±2 px）；同名 1.000、不同名最高 0.894；門檻 0.95 + 與次佳差 0.05，否則 None。卡片 < 5 時順序不可靠，樣板命中即直接採用。
- `team.py status` 自動用（全命中就不跑 OCR）：2.7 s（比 OCR 版 3.5 s 快 0.8 s）。`--no-ocr` 不讀名字。
- 學樣板：切換面板開著、5 人都在線時 `uv run --no-project python tools/gui/namematch.py learn`（順序 + OCR 交叉確認）；`read` 看分數、`list` 看樣板。換版面 / 字型後要重學；新角色要先加進 watch-config.json 的 chars。
- 樣板檔不進 git（`tools/.cache/`）。程式用 `namematch.read_names()` → `{卡位: 名字或 None}`。
