# 設置（setting）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「設置」1210,760。關閉點右上 X **1340,85**（ESC 關不掉）。
左側分頁：
- 聲音設置 230,195：關閉聲音、背景 / 音效音量。
- 畫面設置（預設）230,278：鏡頭高度（滑桿 y≈217，滑塊範圍 x≈633～1190）、戰鬥視野（y≈321）、幀率 30 / 60 / 無限制。
  - **規則：鏡頭高度一律拉到最左**（walk.py / heal.py 的每格位移以此為準；滾輪也會改鏡頭高度，不要在遊戲畫面上滾滾輪）。戰鬥視野只影響戰鬥畫面。
- 其他設置 **230,360**：顯示名字、遮罩玩家、交易開關、自動吃肉、戰鬥翅膀、決鬥請求、隱蔽日誌、全部遮罩、選擇語言。
- 聊天設置 **230,444**：系統 / 家族 / 隊伍 / 地圖 / 世界頻道、字色。
下方資訊列：暱稱（＝目前操作角色）、等級、角色ID、**離線時間剩餘**、鎖屏。
