## 關閉方式
- 一般面板：`key '{ESC}'`，或面板右上紅色 ✕。
- 聊天面板：左上紅色 ← 在 **735,89**（只在聊天面板開著時點）。
- 小地圖浮窗：再點 1350,175。
- 收合狀態：見上表各自的新座標（收合鈕會換位置）。

## 走路（點地面，2026-10-09 實測）
**要移動就用 `tools/gui/walk.py`**（自動找路 + 點地面 + 驗證，見 SKILL.md「移動」）。下面是它依據的實測規則；
**數字（每格位移、每次最多格數、UI 禁點範圍、引子座標、每格秒數）以 walk.py 開頭的常數為準**，這裡不重複寫死。
- 角色固定在畫面中央附近（腳下，walk.py `ME`），點地面就走過去，鏡頭跟著移動。
- 每格的螢幕位移：x+1 往右上、y+1 往右下（walk.py `TILE_X` / `TILE_Y`；換算用 `walk.screen(dx, dy)`）。
- 點的格子遊戲會**自己尋路繞障礙**（例：薩姆吉爾 92,99 往上點 8 格，會先繞到 87,97 再上去）。一次點最多 `MAX_TILES` 格（實測 10 格 OK）。
- 點擊位置不能落在 UI 上（walk.py `UI_RECTS`）：左側任務 / 組隊面板與「詳情」「<」鈕（x 75～395）→ 往左（dx+dy 為負）一次最多約 9 格、往左上斜走只有 4 格；
  上排 HUD 下緣（實測點 459,134 沒反應）、左下聊天區、底部按鈕列、右上小地圖鈕、右下遇敵鈕。點到 UI 或點到實際走不到的格子，角色不會動（`waitstill` 回 `nomove`）。點到 NPC 會變成對話。
- **走路速度約 0.15～0.17 秒 / 格**（7～8 格 1.25～1.35 秒，含起步）。HUD 右上座標比角色慢半拍更新，走路中讀到的座標不準，要停下來再讀。
- **走完要等鏡頭停住才能點下一段**：點擊是相對鏡頭中心換算格子，走路中點會偏。連點用 `gui.sh seq` + `waitstill`（等畫面停下來），不要估秒數。
- **換地圖（傳送、走出口）後的第一下左鍵會被吃掉**（等 4 秒再點也一樣；右鍵當引子無效）。先點一下右上狀態列空白 **1215,18**（沒有按鈕）當引子，再點正事（walk.py 每次開走都會先點）。
- 直接點 NPC（3 格以外也行）會自己走過去並開對話；但走路途中點 NPC 常常變成點到地面，要停穩再點（walk.py `npc_steps` / `talk_npc`）。
- 小地圖浮窗（1350,175）裡點位置**不會**自動尋路。
- 通行格：`knowledge/data/maps.bin`（`psa.py grid` 可看）。座標跟遊戲一致（薩姆吉爾石台 x88～98 y95～100、雕像 x78～83 y74～79 都對得上），
  但**障礙邊緣不完全準**（1000:74,75 資料說可走、實際點了不會動），所以 walk.py 找路時離牆遠一點。
  部分室內圖資料對不上（醫院 1005 資料 30×30，實際座標到 25,65）→ walk.py 自動改成直線分段、讓遊戲自己繞。
- 進醫院的抵達點 1005:25,65 本身就是出口格；要出去就先走開（實測到 25,62）再走回 25,65（`walk.py 1005 25 65 --exit 1000`）。站在出口上點自己腳下會不會出去未實測。
- 實例：回村補血 `tools/gui/heal.py`（92,99 → 醫院固定 5 段 + 小護士），紀錄見 `notes/leveling.md`。
- **組隊狀態下隊長不能和部分 NPC 互動**（日誌「組隊狀態下無法和NPC互動」，例：鬥技場嚮導）→ 先解散。
