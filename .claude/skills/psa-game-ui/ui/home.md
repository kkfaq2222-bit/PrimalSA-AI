## 關閉方式
- 一般面板：`key '{ESC}'`，或面板右上紅色 ✕。
- 聊天面板：左上紅色 ← 在 **735,89**（只在聊天面板開著時點）。
- 小地圖浮窗：再點 1350,175。
- 收合狀態：見上表各自的新座標（收合鈕會換位置）。
