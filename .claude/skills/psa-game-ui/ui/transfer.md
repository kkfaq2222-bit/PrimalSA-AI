# 地圖傳送（newmaptransfer）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。
> 2026-10-09 實測（DKB0 隊長，0 轉 1 級，五人隊）。

## 入口與版面
- 主畫面右上圓形「傳送」鈕 1340,65 → 開「地圖傳送」面板（預設停在尼斯大陸分頁）。ESC 或 X 1290,97 關閉。
- 左側分頁：尼斯大陸 259,196 / 練級傳送 **259,314** / 便捷傳送 **259,432** / 英雄戰場 **259,549**。
- **點目的地標籤 = 立刻傳送**：沒有確認框，不扣石幣（實測 100,000 不變），先出現約 1 秒 Loading，隊伍跟著隊長一起過去。
- 等級不夠：不傳送、**面板保持開著**，聊天日誌出現「DKB0未達到0轉N級禁止傳送」。

## ⚠ 點擊只在面板範圍內有效
面板開著時，點面板外面（例：再點一次 1340,65 想「重開」面板）會**穿透到遊戲場景**，可能走路或點到 NPC（實測開了老村長對話）。
- 被擋之後面板還開著 → 先 `key {ESC}` 關掉，再重開。
- 安全寫法：`click 1340 65; wait 800; click <分頁>; wait 600; click <目的地>; wait 2500; key {ESC}`。傳送成功後面板會自己關，多按的 ESC 在主畫面沒有作用（實測）。
- 傳送後先截圖，看右上角「地圖名 ID:x,y」確認位置。
