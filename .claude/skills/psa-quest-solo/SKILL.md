# 單人逃跑解任務（跑路 → 到 NPC 停 → 組隊 → 對話 / 打 → 再解散）

**REQUIRED BACKGROUND:** 先載入 psa-game-ui（紅區、驗證視窗立刻停手）。會用到 `/psa-disband-team`、`/psa-quick-team`、`/psa-grind-start`。
座標是截圖座標（客戶區 2880×1659）。`G="bash tools/gui/gui.sh"`、`Q="uv run --no-project python tools/gui/quest.py"`，在專案根目錄執行。
介面細節 / 實測：`../psa-game-ui/ui/quest.md`「單人逃跑解任務」、`ui/team.md`、`ui/transfer.md`、`ui/ass.md`。

## 0. 規劃（先查資料，不碰畫面）
```bash
uv run --no-project python tools/query/psa.py steps <任務組ID或任務名>     # 例：steps 2031
```
每步印出 NPC @ 地圖座標、**[對話] / [戰鬥] / [打怪(人工)]** 與判斷依據：
- 戰鬥 = 該步 endScript 的 NpcScript func 為 `taskBattle` / `fightBattle`，或 Task.type = 4。語意是「可能戰鬥」（2024 龍的巢穴資料是 taskBattle 但實際沒打），一律當戰鬥處理。
- 打怪 = Task.type = 2（MONSTER）：要先把怪打掉才能交，**不能逃，標「需人工規劃」**，不要用這套流程硬跑。
- 其餘 = 對話（若印「※類型N非一般對話」＝ 物品 / 寵物 / 答題 / 巡邏等，先人工確認）。
範例 2031（英雄島前傳）：步 1～5、7、8 對話；**步 6 戰鬥**（龍王的守衛 @ 龍穴門口 5510:53,17，taskBattle group 100018）。

## 1. 每階段開始前：DKB0 戰鬥設定全關
完整戰鬥畫面才有「逃跑」鈕，所以 DKB0 的 外掛 → 原地遇敵 / 自動逃跑 / 快速戰鬥 / 自動戰鬥 **都要關**（每角色各自設定；隊員不用動）。
```bash
$G seq "click 1300 760; wait 900; pixel 146,343/315,343/484,343/146,400"     # 255,255,255 = 關；其他值 = 開
# 哪個不是 255 就點哪個（146,343 / 315,343 / 484,343 / 146,400），切換式：點完再讀一次確認
$G seq "pixel 146,343/315,343/484,343/146,400; click 1318 90"                 # 四個都 255 才關面板（X 1318,90；ESC 無效）
```
- 先確認外掛左上選的是 DKB0（黑點 137,151）。
- 完成後恢復掛機用 `/psa-grind-start`（快速戰鬥、自動戰鬥、原地遇敵要重開）。

## 2. 對每一步重複（一步 = 一個 NPC）
1. **解散隊伍**：`/psa-disband-team`（已是單人就跳過）。DKB0 單人。
2. **單人巡路到 NPC**：
   ```bash
   $Q --solo --task "<追蹤列表上的任務名>" --max-seconds 900; echo exit=$?
   ```
   - 途中遇怪 → 完整戰鬥畫面 → 自動按「逃跑」1283,168，失敗下回合再按（實測 6 場全部 1 秒內按、每場 1 次）。
   - 到 NPC 跳出對話框 → **ESC 關掉、不回答任何選項** → 印「到達 NPC」→ **退出碼 20**，停下交給組隊。
   - 被打飛（回薩姆吉爾村儲存點附近）→ **退出碼 21**（見第 3 節）。
   - 其他退出碼：2 不認得的畫面（答題 / 驗證 → 停手通知使用者）、3 追蹤沒反應（改手動 walk.py + 點 NPC）、5 找不到任務、4 參數 / 版面。
3. **一鍵組隊**：`/psa-quick-team`（隊員會被拉到隊長旁；組完隊長 DKB0 是當前角色）。
4. **依 `psa.py steps` 的類別完成這一步**：
   - **對話步**（組隊 → 對話 → **立刻解散**，一律這個順序）：
     `$Q --task "<任務名>" --stop-after-dialog --disband-after --max-seconds 120; echo exit=$?`（有「獲得物品」視窗的步驟也可用 `--stop-after-rewards 1 --disband-after`）。
     腳本點 NPC 頭上黃「?」或追蹤列表開對話、按左鈕、領獎；**這步一旦對過話 / 領過獎，之後絕不再點追蹤 / 黃問號**，連續閒置 2 次就停（所以不會把下一步也對完、不會接著巡路），停下後 `--disband-after` 自動：切左側組隊分頁 → 驗證分頁 → 點隊長列 → 驗證選單彈出 → 點解散 → 驗證畫面變了。每步驗證不過就停、不亂點（退出碼 26）。
     **完成後一定 `$G shot` 確認左側只剩「創建隊伍」**（解散驗證是像素變化，不是辨識文字），再進下一步。沒帶 `--disband-after` 時，對話一完成就要手動 `/psa-disband-team`，**在任何巡路之前**。
     退出碼：0 步完成（有 `--disband-after` = 已解散）、24 步完成後遊戲自己又開始 Auto Walking（腳本沒點追蹤；有 `--disband-after` 時已先解散；要立刻確認狀態）、26 解散沒做成（分頁沒切過去 / 選單沒彈出 / 解散後畫面沒變；shot 看畫面，手動 `/psa-disband-team`）、25 見下表。
   - **戰鬥步**：**一定先站到 NPC 旁**（`--fight` 不巡路、不點任務追蹤；第 6 步見第 4 節的便捷傳送），DKB0 外掛 **快速戰鬥關**。
     `$Q --fight --task "<任務名>" --npc auto --max-seconds 300`（`--npc X,Y` = NPC 地圖座標；`--npc auto` 由 `psa.py steps` 找戰鬥步的 NPC；自己座標 OCR 讀，可用 `--at X,Y`；已手動點過 NPC 改用 `--no-click`）。
     流程：點 NPC → 對話左鈕 → 開打。**只有點 NPC / 按對話框後 15 秒內（QUEST_BATTLE_WINDOW）開始的戰鬥才是 BOSS 戰**：確保自動戰鬥開、打完連續閒置 2 次 → 印「BOSS 戰結束」退出碼 0（不再巡路）。其他戰鬥一律是小怪：自動戰鬥開著先關、再按逃跑。
     新退出碼：**22 點 NPC 後 12 秒沒對話框也沒戰鬥（沒點到 NPC / 被小怪打斷）**、**23 對話後 15 秒沒開打**，都不會自己亂走，回報後人工處理。
5. 回到 1（下一步；下一步 NPC 在同圖時 DKB0 仍在隊伍中也沒關係，解散後才單人跑）。

## 3. 被打飛（退出碼 21）
- 現象：`quest.py` 偵測到位置在 1000 儲存點（薩姆吉爾的儲存點巫女 1000:94,99）附近且上一個位置不在那裡。存圖 `tools/.cache/quest-log/*-KNOCKED.png`，先 shot 確認。
- 補血：`uv run --no-project python tools/gui/heal.py --no-return`（傳送村子 → 醫院小護士「恢復氣血」，**不傳回練功點、不開原地遇敵**，約 17 秒）。
- **逃跑途中被打飛**（步 2）→ 補完血，`$Q --solo --task ...` 從醫院巡路回 NPC（自動巡路從村子跨圖回任務點：未實測，不行就用傳送 / walk.py 到附近）。
- **戰鬥步被打飛**（步 4 的 `--fight`）→ 補完血就**停下回報使用者**（打不過，要評估等級 / 隊伍配置，不要無腦重打）。
- 隊員是單人狀態時被打飛的是各自的角色；補血只補「當前角色」所在隊伍，組隊後再補一次。

## 4. 紅暴任務（2031 英雄島前傳，每轉必解）專屬
步 1～5：照第 2 節的通用流程（NPC：避難洞窟 5500 老爺爺接任務 → 薩姆吉爾 5501 / 5503 / 5505 / 5506 / 5508，座標以 `psa.py steps 2031` 為準，每步對話步）。
**步 6（戰鬥）不巡路，直接傳送**：
1. **第 5 步拿到第 5 顆勾玉後不解散隊伍**（全隊直接過去；DKB0 外掛設定同第 1 節：快速戰鬥關）。
2. 隊長地圖傳送 1340,65 → **便捷傳送 259,432** → **龍王守衛 1160,646**（直接傳送到龍穴門口 **5510:50,17**；龍王的守衛 NPC 在 53,17；免費，使用者確認；抵達點未實按驗證，見 `ui/transfer.md`）。`$G seq "click 1215 18; wait 100; click 1340 65; waitpix 1500 1290,97,197,73,49; ifok click 259 432; ifok wait 600; shot"` 看到 龍王守衛 標籤再 `click 1160 646`，抵達後 `stat.ps1` 看 pos 的地圖 = 5510。
3. 隊伍已在一起就不用重組；若有人脫隊才 `/psa-quick-team`。抵達 5510:50,17 後**不要先跑 --fight 的巡路**（沒有巡路了）。
4. 快速戰鬥確認關 → `$Q --fight --task 英雄島前傳 --npc 53,17 --max-seconds 300`（點龍王的守衛 NPC 3641 @ 5510:53,17 → 對話 → BOSS 戰自動戰鬥 → 「BOSS 戰結束」）。途中小怪會被逃跑。退出碼 22 = 沒點到 NPC，shot 看站位後重跑。
5. **打完確認 5 人都在隊伍（必做）**：
   - 組隊面板 850,760：一次 pixel 讀 5 格 `pixel 294,320/493,320/692,320/891,320/1090,320`：**5 個都是米色（R > 230）= 5 人**；有深棕 ≈ (120,88,63) = 該格是空的 +（細節 `ui/team.md`「判斷隊伍幾個人」）。讀完 `{ESC}`。
   - 用切換面板 763,760 交叉確認：1 個「隊長」+ 4 個「隊員」；有「單人」= 脫隊（`{ESC}` 關）。
   - **少於 5 人** → 有人脫隊（戰鬥掉線 / 被踢 / 打飛後各自回村）。處理：點切換面板該角色卡片（DKB02 930,300 / DKB03 620,385 / DKB04 930,385 / DKB05 620,470 / DKB0 620,300）把它換成當前角色 → 先看它是不是已在 5510（不在就自己便捷傳送 → 龍王守衛）→ `/psa-quick-team` 時**隊長選脫隊角色**（上排「隊長」格要截圖看哪一格是它，座標不一定是 549,320）→ 對話開打、自動戰鬥，打完再確認 5 人；逐一處理到每人都完成步 6（每個人要有「打敗龍王守衛」的完成）。**脫隊重組這條流程未實測**。
6. **（使用者 2026-10-10）步 7 龍王對話卡住＝有人寵物欄滿 → 停下回報；對話順利完成就直接進步 8，不用逐人確認巴朵蘭恩。**
   步 7：和龍王對話（龍穴 5511:16,13）：`$Q --task 英雄島前傳 --stop-after-rewards 1`；確認 5 人各得寵物「巴朵蘭恩」（日誌「獲得寵物」＋寵物面板 / 背包左欄頭像逐一看，不要只看隊長）。
7. 步 8：回薩姆吉爾村老爺爺的家 1013:14,16 交勾玉（找老爺爺的孫女 NPC 3700）：組隊狀態下 `$Q --task 英雄島前傳 --stop-after-rewards 1`（巡路跨圖若不行：城鎮傳送薩姆吉爾 750,507 → 走到 1013）。
8. 收尾：5 人各自把「英雄的祝福」×5 存進**個人倉庫**（背包 → 倉庫 1318,467 → 確認是「個人」分頁 → dclick；左欄頭像切角色逐一做；使用者 2026-10-10 指定，見 `ui/bag.md` 保留表）。
9. 完成：寫 `notes/quest-log.md`（每個任務都要記錄）、`notes/quests-plan.md` 標「紅暴任務，每轉必解」；`/psa-grind-start` 恢復掛機（5 人快速戰鬥 + 自動戰鬥 + 隊長原地遇敵），最後 `$G end`。

## 檢查點與失敗對照
| 現象 | 原因 / 處理 |
|---|---|
| `--solo` 遇敵沒按逃跑，日誌「沒有完整戰鬥畫面」 | DKB0 快速戰鬥還開著（只有頭上 VS 牌）→ 回第 1 節關掉；之後那場只能等它打完 |
| 完整戰鬥但一直不逃跑 | 自動戰鬥還開著（指令框根本不出現，直接「播放中」）→ 關 DKB0 自動戰鬥；或版面不是 2880×1659（`$G info`） |
| 逃跑失敗一直留在戰鬥 | 逃跑有機率失敗，腳本每個「下指令」階段按一次；連續 5 次以上就停下看 HP，必要時手動點 1283,168 |
| `--fight` 沒按自動戰鬥鈕 | 鈕本來就是開（刀劍動畫，不是靜止紅圖示）→ 正常；或看不到完整戰鬥（快速戰鬥沒關） |
| **2026-10-10 紅暴：第 5 步後 `--fight` 點追蹤巡路去龍王守衛，途中遇小怪，舊版對任何戰鬥都按自動戰鬥 1380,600 把小怪戰當 BOSS 一路打，DKB0 根本沒點到龍王守衛** | 已改：`--fight` 不巡路；BOSS 戰 = 點 NPC / 按對話框 15 秒內開始的戰鬥，其他是小怪（關自動戰鬥 + 逃跑）；沒點到 NPC 退出碼 22 |
| `--fight` 退出碼 22 / 23 | 22 = 點 NPC 後沒反應（站位太遠 / NPC 被擋 / 剛被小怪打斷）→ shot 看畫面，走近後重跑；23 = 對話後沒開打（這步可能不戰鬥，或條件未達）|
| 退出碼 20 但畫面還有對話框 | ESC 沒關 → 手動 `$G key '{ESC}'`；**絕不點任何選項** |
| 退出碼 21 但其實沒被打飛 | 任務 NPC 本來就在村裡儲存點附近時，若上次位置讀不到會漏判，不會誤判；有疑慮先 shot / stat 看 pos |
| 出現答題 / 驗證視窗 | 鐵則 5：**立刻停手通知使用者**（quest.py 退出碼 2） |
| **2026-10-10 琉璃：解散隊伍沒成功，整個任務變成 5 人組隊跑** | 換圖後第一下點擊常被吃掉；左側任務追蹤條目在 y≈325，盲點 210,320 / 200,372 會點到追蹤觸發自動巡路。解散前先截圖確認左側真的是「組隊」分頁，解散後確認只剩「創建隊伍」才開始 `--solo` |
| 連續對話步（例：琉璃步 1→2）用 `--stop-after-rewards 1` 停不下來 | 沒有獲得物品視窗的對話步不會觸發停止，腳本會一路巡路到下一步 → 對話步改用 `--stop-after-dialog` |
| **`--stop-after-dialog` 跨步不停**（深紅步 1→2）原因（2026-10-10 已修） | 舊版對話完第一次閒置就去點黃問號（步 2 NPC）、領過獎勵後又整列掃追蹤並點它；現在這步已對話 / 領獎後閒置只數數（2 次就停），絕不點追蹤 / 黃問號。仍保險：一定帶 `--disband-after` 或停下後馬上解散 |
| 組隊模式（非 --solo/--fight）的完整戰鬥卡在下指令 | 已改（2026-10-10）：預設模式完整戰鬥看到自動戰鬥鈕是「關」就按 1380,600（小怪讓全隊自動打完，**不逃跑**）。同一場按 4 次仍關（寵物指令視窗等）→ **退出碼 25**：人工處理（戰寵視窗先選攻擊 + 選擇 1165,363 / 1165,690，或 shot 看卡在哪）。`--solo` 仍逃跑、`--fight` 仍是 BOSS 判斷 |
| `--disband-after` 退出碼 26 | 分頁沒切到「組隊」（換圖後第一下點擊被吃，已連點 2 次仍不行）/ 點隊長列後選單沒彈出（沒點解散，避免點到第 2 列成員或 y≈325 的追蹤條目）/ 點解散後左側畫面沒變。`$G shot` 看左側，必要時手動 `/psa-disband-team`。**本機制只在模擬驗過，實機未驗**；單人狀態（沒隊伍）時不要跑 `--disband-after`（點 210,320 可能點到「創建隊伍」） |
| **2026-10-10 深紅：`--stop-after-dialog` 連續兩個對話步（步 1→2）沒停，組隊狀態自動巡路進洞，途中遇敵 + 換圖吃點擊 → 一直解散不成功，變成組隊跑** | 步 1 組隊對話完就立刻解散（對話框關閉、尚未 Auto Walking 時），或步 2 也先單人 `--solo` 跑到守人旁（退出碼 20）再組隊對話；組隊巡路中遇完整戰鬥要手動按自動戰鬥 1380,600（寵物指令視窗先選攻擊 + 選擇） |
| 組隊訊息 33231「不支持一鍵組隊」 | 地圖禁止組隊或有人狀態異常 → 回報使用者，不要自己換圖 |

## 實測狀況（2026-10-10 紅暴跑完）
