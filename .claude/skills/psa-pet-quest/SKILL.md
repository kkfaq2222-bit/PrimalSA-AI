# 交寵物任務（抓 → 分 → 練 → 交），以恐龍博士 2016 / 卡坦的願望 2019 為例

**REQUIRED BACKGROUND:** 先載入 psa-game-ui（工具、紅區、驗證視窗立刻停手）。會用到 `/psa-disband-team`、`/psa-quick-team`、`/psa-grind-start`；寵物面板細節見 `../psa-game-ui/ui/pet.md`、倉庫見 `ui/bag.md`、外掛見 `ui/ass.md`。
座標是截圖座標（客戶區 2880×1659）。`G="bash tools/gui/gui.sh"`，在專案根目錄執行。實測日 2026-10-10，隊伍 角色 1～5（真名 DKBO、DKBO2～5）（0 轉 128 級）。
**轉生或吃封印書後這些任務會重置，要整套重做**（先用 `psa.py` 查任務等級、寵物 ID 是否改變）。

## 何時用
- Task 步驟類型是交寵物（`psa.py steps <任務ID>` / `knowledge/quests/`：寵物 ID × 數量 + petLevel），或使用者說抓寵 / 練寵交任務。
- 條件：petLevel 是「≥」（實測 18 / 25 / 30 都過），交出的寵物會被收走（clean=1），寵物只是消耗品。**每個角色各要一套**。

## 前置
- **當前角色一律維持角色 1**，不用切換面板換人。
- 寵物 / 道具 / 倉庫：開左上「寵物」或「道具」面板，用**面板左側頭像**切換角色（寵物面板 318,80；頭像 角色 1 82,210 / 角色 2 82,340 / 角色 3 82,470 / 角色 4 82,599 / 角色 5 82,695）。**先確認面板真的開了再點頭像**（否則會誤點左側任務追蹤）。
- 外掛（1300,760）用面板內角色欄選人。
- **只有逐人交任務時**才用切換面板（763,760 開）：卡片 角色 1 620,300 / 角色 2 930,300 / 角色 3 620,385 / 角色 4 930,385 / 角色 5 620,470（以 ui/team.md 為準）；換人後角色在原地；交完切回角色 1。

## 四條核心規則
1. **從倉庫取出 / 抓到的寵物預設「等待」**：練寵前每人要把第一隻按「出戰」（390,703），其餘交給自動轉換戰寵。沒有出戰寵就拿不到經驗。
2. **交寵物任務前，所有任務寵都要變成「休息」**：自動轉換戰寵會把後面的寵物換成出戰；卡坦曾因一隻鯊在出戰，按「完成」21 次都不前進。
   **快速做法（使用者 2026-10-11）**：對**第一順位（第一格）的寵物**依序點「騎乘」532,702 → 「出戰」390,702 → 「休息」672,702，這樣全部寵物都會變休息（不必逐隻改）。做完看寵物格紅標確認沒有「戰鬥 / 騎乘」。第一格若是騎寵瑪斯貝卡，騎乘會動到它，做完要確認它的狀態（見規則 3、收尾）。
3. **寵物存倉絕不選第一格騎寵（瑪斯貝卡）**：按「存入寵物」前截圖確認選中名稱，依名字不依格位（曾兩次選中騎寵，一次真的存進去，要取回改騎乘）。
4. **寵物倉庫存入 / 取出用按鈕，不能點兩下**：存入 530,697、取出（選格後）675,703。**只有道具倉庫才可點兩下**。

## 流程
### 0. 準備
- 外掛「一般設置」取消鎖定戰寵（656,377；先 pixel 確認是勾的才點）。
- 寵物面板 → 右側「倉庫」1365,440 →「個人」897,170 /「公共」1160,170。5 人寵物欄只留騎寵（瑪斯貝卡），其他寵物選格（250,200 / 322 / 445 / 567 / 690）→ 存入寵物 530,697，存進**個人倉庫**（每次 1 秒內成功，後面格子往前補位）。
- 公共誘餌：背包 → 倉庫 1318,467 → 公共 547,200，點格 237,292 → 浮窗「取出」732,648（整疊全取）。誘餌用完會自動取消勾選自動抓寵。

### 1. 抓（外掛「捉寵設置」984,212）
- **角色 1（人物）最後才抓，由人物自己操作**：抓寵時不能快速戰鬥，會進入戰鬥畫面（畫面以角色 1 為主）。先由角色 2～5 抓；非當前角色也能抓、會被系統送去抓，角色 1 畫面不變。
- 抓前：關原地遇敵、解散隊伍（`/psa-disband-team`）。
- 誘餌拆分：該角色背包點誘餌 860,352 → 浮窗「拆分」628,648 → 點數量欄 755,451 跳數字鍵盤 → 輸入 N → 確認 908,574 → 確定 610,545（取消 828,545 / X 950,205）。**N = 可抓捕數 = 要抓的隻數**。剩下的整疊存回公共：倉庫公共分頁下，背包格 dclick 966,352（道具倉庫可點兩下）。
- 外掛選角色（左上 298,151）→ 系別下拉 921,377（清單 8 項，用 drag 750,650→750,480 捲）→ 寵物下拉 1283,377 → 可抓捕數（1213,315）確認 = N → 勾「自動存倉庫」820,315 → 勾「自動抓寵」656,315。
- 約 1.5 分鐘抓完 2 隻（5 隻約數分鐘）；抓完遊戲自己取消「自動抓寵」，可抓捕數歸 0、誘餌歸 0；失敗不額外扣誘餌（誘餌數 = 隻數）。寵物進**寵物欄**（欄未滿時；滿了才進個人倉庫）。
- **抓寵角色的快速戰鬥會被遊戲關掉**，之後恢復掛機要逐人重查。
- 抓寵期間每 30 秒截圖，出現驗證視窗立刻停手。

### 2. 分（共用寵物倉庫 20 格；個人倉庫 20 格）
- 抓一種分一種：抓的人自己留 1 隻，其餘存共用（存入寵物 530,697）；其他人從共用取出（選格 → 取出 675,703，每次 1.5 秒內成功）。逐人驗收：寵物欄 = 騎寵 + 任務寵（卡坦 4 隻剛好滿 5 格）。

### 3. 練（地點：柯奧4F龜洞 Lv80，練級傳送 → 柯奧山的小洞窟４樓 11004）
- 外掛左欄勾「自動轉換戰寵」（轉換級數使用者已設 30，所有任務寵統一練到 30；練完**取消勾選**）。
- 每人第一隻按「出戰」390,703（規則 1）。
- `/psa-quick-team` 組隊 → `/psa-grind-start`（原地遇敵 + 5 人快速戰鬥逐一確認）。
- 監測：寵物面板逐人點頭像讀寵物等級；全部達標才收。交前逐人確認每隻都在、等級都到（否則整隊「條件不滿足」）。
- 流程順序：先全部抓好 → 全部練好 → 再交。

### 4. 交
- 第一格寵物依序點 騎乘 → 出戰 → 休息，讓全部任務寵變休息（規則 2 快速做法）。
- **恐龍博士（2016，11006 博士的研究所）**：組隊 → 任務詳情支線「恐龍博士」傳送到研究所 → 接任務（哈魯 11,11）→ **隊長解散、逐人交**。吉魯 11,7「恐龍博士」→「完成」（步 1，魯尼帖斯 Lv18+）→ 跳「選擇」寵物視窗（兩張卡，順序每人不同，**看名字選**）→ 點卡片 → 確定 706,614；步 2 點任務追蹤 205,325 巡到哈魯 → 完成 → 選擇視窗（貝魯卡 Lv30+）→ 確定。每人 10 秒內，逐人用切換面板，交完切回角色 1。
- **卡坦的願望（2019，薩伊那斯 100:230,180）**：**5 人組隊、隊長角色 1 交一次，5 人同時完成**（步 1、步 2 都是）。交完逐人確認追蹤進步 2 / 寵物被收走。`quest.py --task 卡坦的願望` 可用，quest.py 偵測到同一 NPC 對話重複無進展會以退出碼 33 停手（2026-10-10 加入）。

### 5. 獎勵處理
- **布克布克（恐龍）、修寶（卡坦步 1）可丟**：寵物面板選該格（250,322）→ 垃圾桶 708,565 → 提示窗**確認名稱** → 確定 615,557。**只限這兩種**，其他寵物一律不丟。
- **朵拉比斯（卡坦步 2，另有綁定鑽石 5）**：存個人倉庫。

### 6. 收尾
- 取消「自動轉換戰寵」勾選；取回原寵物（迪基格斯等）、恢復出戰 / 騎寵（外掛鎖定戰寵 / 鎖定騎寵重勾，先確認騎寵還是瑪斯貝卡）。
- `/psa-grind-start` 恢復掛機（抓寵角色快速戰鬥被關，要逐人重查）。
- 寫 `notes/quest-log.md`（抓寵耗時、誘餌消耗、交任務有無挑寵物視窗、失誤）。

## 紅區
- 可抓捕數「+」1295,315（推測花石幣 100,000）、「丟棄不滿足條件的寵物」勾選與 攻< / 防< / 敏< SET、寵物面板回爐 372,610、召喚 / 升星 / 兌換、任何鑽石、倉庫擴容 / 解鎖新頁。
- 垃圾桶 708,565 只准丟布克布克 / 修寶（丟前截圖確認名稱）；其他寵物一律不丟。
- 答題 / 驗證視窗：立刻停手通知使用者（鐵則 5）。戰鬥中不可開外掛面板（等 VS 牌消失）。

## 失敗對照
| 現象 | 原因 / 處理 |
|---|---|
| 練了很久寵物沒經驗 | 沒有出戰寵（取出的寵物預設等待）→ 按「出戰」390,703 |
| 對 NPC 按「完成」一直重複開場白不前進 | 有任務寵在「出戰」→ 全部改等待 / 休息再交 |
| 騎寵不見 / 騎乘被取消 | 瑪斯貝卡被存倉 → 從個人倉庫取出（675,703）、寵物面板按「騎乘」、外掛重勾鎖定騎寵 |
| 點頭像卻跳「接取任務條件不達標」 | 寵物 / 道具面板沒開就點左側頭像，誤點任務追蹤 → 關掉對話，先確認面板再點 |
| quest.py 隊伍檢查退出碼 30 / 32 | 切換面板沒打開（安全失敗）→ 重跑 |
| 40000000069「隊中[X] 條件不滿足」 | 有人少寵物 / 等級不夠 / 寵物在倉庫 → 逐人確認寵物欄（組隊交時） |
| 寵物倉庫點兩下沒反應 / 怪異 | 寵物倉庫只能用按鈕（530,697 / 675,703） |
| 40000000015「沒有寵物儲存空間」自動抓寵停止 | 寵物欄 + 個人倉庫滿 → 先清空位 |
| 40000000013「抓捕罐頭不足」 | 誘餌用完（正常結束） |
| 恢復掛機後抓寵角色沒快速戰鬥 | 抓寵會關掉 → 逐人重勾 |
